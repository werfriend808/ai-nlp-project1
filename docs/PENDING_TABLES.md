# Pending Tables (검증 실패 / 미확정 후보)

카탈로그 확장 중 tblId를 확정하지 못했거나 API 검증에 실패한 후보를 기록한다.
**여기 기록된 후보는 재조사 전 반드시 먼저 확인하고, 중복 조사하지 않는다.**

---

## 창업기업동향

- 조사한 tblId: `DT_142N_G201`(업종별 창업기업수), `DT_142N_G204`(지역별 창업기업수)
- orgId: 142 (중소벤처기업부)
- 시도한 내용:
  - `getMeta`(TBL/ITM)로 표 존재 및 분류축 확인 완료 (업종별 A1/A11/B1... , 지역별 15142A2XX, itmId 16142T1/T001/T002)
  - `statisticsParameterData.do`로 실제 데이터 조회 시도: prdSe=Y/Q/M/F, 기간 2010~2024 등 다수 조합
- 실패 원인: orgId는 맞는 것으로 보이나(err21 아님) 모든 조합에서 `err30(데이터가 존재하지 않습니다)` 반환. 실제 데이터 접근 파라미터를 특정하지 못함.
- 다음 조사 시도: KOSIS 목록 API(`statisticsList.do`)로 이 표의 실제 하위 조회 예시(콤보) 확인, 또는 중소벤처기업부 공공데이터포털 원본 API 문서 대조.

## 연체율

- 조사한 tblId: `DT_376_10_SDMA052V_1` ("[은행] 36. 기업 및 가계대출 연체율(원계열) - 1일 기준")
- orgId: 376
- 시도한 내용:
  - `getMeta`(TBL)로 표 제목이 정확히 "기업 및 가계대출 연체율"임을 확인 — 개념은 정확히 일치
  - `getMeta`(ITM)로 분류축 확인: 분류1(은행종류: 일반은행/특수은행/은행전체, 코드 `13102115396B.01~15`), 분류2(대출종류: 기업/중소기업/가계 등, 가계=`13102115396A.03_C`), itmId 고정값 `13103115396T1`
  - `statisticsParameterData.do`로 실제 데이터 조회 시도: prdSe=M/Q/Y, 기간 202301~202401 등, 은행종류 5개 코드(11~15) × 가계 코드 조합 다수 시도
- 실패 원인: 모든 조합에서 `err30(데이터가 존재하지 않습니다)` 반환. orgId=376 자체는 유효(err21 아님)하나 실제 데이터에 접근하는 파라미터 조합을 특정하지 못함. "1일 기준"이라는 표 제목이 암시하듯 일반적인 M/Q/Y 주기가 아닐 가능성도 있음.
- 다음 조사 시도: prdSe='D'(일 단위) 시도, 또는 금융위원회 금융통계정보시스템(FISIS)이 원출처라 KOSIS Open API로는 애초에 데이터가 연계 안 돼 있을 가능성 확인 필요 (e-나라지표 조회 결과 출처가 "금융통계정보시스템"으로만 명시되고 KOSIS 링크가 없었음).

## 농산물 품목별 소매가격

- 조사한 tblId: 확정 후보 없음 (`DT_1EA1201`은 "주요지표(농가경제)"로 무관한 표)
- orgId: 미확정
- 시도한 내용: "농산물 소매가격", "배추/수박 소매가격", aT 관련 키워드로 다수 검색
- 실패 원인: 검색 결과가 계속 KAMIS(농산물유통정보, aT 자체 시스템, kamis.or.kr)와 공공데이터포털 API로만 연결됨 — KOSIS Open API 표로 통합돼 있다는 근거를 찾지 못함. 이전 세션에서도 동일하게 "aT 자체 시스템일 수도 있음"으로 우려했던 부분이 실제로 확인된 것으로 보임.
- 다음 조사 시도: KAMIS 자체 API(공공데이터포털 15156062 등)를 별도 데이터 소스로 볼지, 아니면 KOSIS 승인통계 목록에서 aT가 생산기관으로 등록된 다른 표가 있는지 재확인.
